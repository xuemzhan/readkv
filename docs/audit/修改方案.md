# 修改方案

核心思路：把论文从"项目日志式撤回声明"改写成"一个有归因、有对照、可复用的评测审计"。方案分四块：定位、补实验、重构文本、投稿路径。

## 一、重新定位（先定，决定后面所有改动）

**建议的主张**：干净基准上，仿射 KV 迁移与零信息对照无法区分；旧基准上的表观成功主要来自泄漏和模板重叠。第二半句要靠下面的 E1 实验才能写。

**建议的贡献列表**（替换现在的"全部撤回/保留/取消"）：

1. 一份缺陷分类和审计流程，覆盖退化对、跨 split 泄漏、实体重叠、模板骨架重叠、聚类 bootstrap 退化。
2. 单缺陷干预归因，也就是现在缺的那一块。
3. 去污染的基准 cf\_pairs\_v2.1 和评测协议。
4. 干净基准上两类映射器（ridge、kd）的负结果。

**标题**可以改成类似 *Leakage Inflates Cross-Model KV Transfer: An Audit of a Counterfactual Benchmark*。具体措辞以 E1 的结果为准。

## 二、补实验（按性价比排序）

| 编号 | 实验 | 目的 | 成本 |
| --- | --- | --- | --- |
| **E1** | **单缺陷干预矩阵**：以 v2.0 为底，分别只加"去重 / 去退化对 / 实体互斥 / 模板互斥"，再与全修复 v2.1 对比。每格 ≥3 seed，指标为 L、dual、E\_CF | 回答"哪个缺陷贡献多少"，是全文最大缺口 | **低**：ridge 是闭式解，无需训练 |
| **E2** | **评测 sealed test 一次**，并与验证集合并 | 补证据量。验证集 8 个 family 加测试集 16 个，合计正好 24，达到你自己设的阈值，可以去掉 exploratory 标签 | 低 |
| **E3** | **每个 seed 的 zero-cache / mismatch / random 对照都给 CI**，对 Joint 做配对检验；"无法区分"的主张改用等价性检验（TOST），预先声明等价边界 | 把"接近但未超过"升级成可检验的结论 | 低 |
| **E4** | **E\_CF 有效性分析**：画 dual 与 E\_CF 的散点（按臂着色）；报告 normalized E\_CF；解释旧语料 E\_CF 只有 1.9–2.1、新语料升到 6.9–8.5，是否来自 \|D\_self\| 量纲变化 | kd 与 affine 的 E\_CF 重叠但 dual 差很大，要正面回应这个张力 | 低（只需重分析） |
| **E5** | **第二个模型对**（4B→1.7B，已有流水线）在干净语料上重跑 | 避免"单模型对"的批评 | 中 |
| **E6** | **补一个已发表基线**，或做参数量匹配的 ridge / kd 变体 | 回应基线不公平 | 中 |
| **E7** | **序列打分扩展**到合并后的全部 F1–F4 pairs | 当前只有 6 个聚类，结论偏弱 | 低 |
| **E8** | **SQuAD 锚点：删除，或重做**（随机抽样多篇文章，换合适的 prompt 或模型，使 Self 不在地板上） | 现状信息量接近零 | 删除最省事 |

**E1 的结果怎么写**（提前定好，避免事后挑选）：

- 若"只去重/只换模板"就复现大部分差距，那么主结论是"表观成功主要来自泄漏"。
- 若没有单一缺陷能解释，就报告为缺陷之间的交互作用。这两种结果在 TMLR 上都能立足。
- 如果 E5 在第二个模型对上方向一致，主张可以写得更强；不一致则明确限定在 1.7B→0.6B。
