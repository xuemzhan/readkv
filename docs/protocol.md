## 0. 与 V1 协议的关系（升级说明）

| 处理 | 内容 |
|---|---|
| **保留** | identity / cache round-trip 实现门；Self / Identity 锚点；错配 / 随机 / 零 / shuffled-target 对照；簇级 paired bootstrap；≥3 seed；同 dtype / 同 kernel；产物不可变；预注册先写后跑；严格零重 Prefill 标志 |
| **替换** | 主终点从 `CHG`（gold-letter prob 变化）改为 **`E_CF`（反事实响应误差）**；exploitability 门（旧 H3）降级为信息归因控制组，不再作为独立“门”；对称 Key 目标从主线挪为机制前置实验；行为 mapper 重构为 `CF-RCT-lite` / `CF-RCT-mech`，并加入 KD / CE / contrastive 公平基线 |
| **新增** | 成对反事实文档构造与六类任务切片；`E_CF` 指标族；五类最小指标体系；Routing / Consumption 局部诊断；贡献表述门槛 |
| **不再争论** | “表示误差是否等于任务质量”；identity 审计、错误内容探针、`R²` 不等于任务质量等前两篇已有结论不得作为第三篇新增理论创新 |

主结论门槛：新方案必须至少在**独立测试集**和**多个训练随机种子**上，对**最强可运行行为基线**给出稳健改善；若只能在合成任务上取得小幅效果，应如实定位为受限研究，不夸大跨域通用性。

## 1. 研究问题与可证伪假设

### 1.1 三个研究问题

| 研究问题 | 证据要求 | 失败时的调整 |
|---|---|---|
| RQ1：反事实响应是否在跨模型迁移中额外失真？ | 在学生原生有效的成对文档中，既有强 Mapper 的反事实误差显著大于原生 / Identity 数值残差 | 若强 Mapper 已基本无失真，转为条件 / 边界研究，不预设新方法胜出 |
| RQ2：能否解释并预测失真来自哪个功能环节？ | 局部 K/V 介入及层 / 头干预能定位，并在独立数据上预测误差 | 若只能事后相关，降低机制主张，重新审查理论模型 |
| RQ3：能否以冻结学生的 Mapper 定向恢复？ | 相同训练预算 / 参数量下，对比最新强基线获得稳定提升 | 若无提升，停止将对比目标命名为核心算法 |

### 1.2 可证伪假设

| 编号 | 可证伪假设 | 预期观测与反例 |
|---|---|---|
| H1 | 高常规任务分数不保证反事实响应保真 | 在原生学生能正确响应的文档对上，某些 Mapper 的响应强度 / 方向与 Self 存在稳定差异；若所有强基线无差异，则 H1 不成立 |
| H2 | 反事实失真可部分归因于 Key 路由与 Value 消费的可识别作用 | 控制 Query 的局部移植可分解误差，并在独立数据上预测跨文档失真；若只得到局部相关而不能外推，则降低主张 |
| H3 | 以反事实响应为约束的机制感知 Mapper 能在同预算下增强保真 | 相同参数、校准样本、学生调用次数下胜过逐样本 KD / CacheLink 类强对照；若无增益则不成立 |
| H4（扩展） | 机制或方法在非等深 / 分布转移条件下保持部分有效 | 至少一组非等深迁移方向、一个额外文档域验证；失败时报告适用边界 |

拟议论文主贡献最少须具备两个相互支撑的证据：①一个可重复且未被基线消除的反事实功能失真现象；②一个可以验证或改善该现象的机制结果。纯粹“多做一套评测”与“在模型上再加一个 loss”均不自动成立为完整论文贡献。三个贡献层次：**评价层**（可复现成对反事实任务 + 预先固定审计）、**机制层**（Routing / Consumption 可解释诊断）、**方法层**（机制指标训练 / 修正 Mapper）。只有评价层新增而无机制或方法改善时，不声称完成高水平方法论文。

## 2. 技术场景与边界

教师模型 `T` 仅对上下文 `d` 做 Prefill 并生成 `C_T(d)`；Mapper `gθ` 将其映射到接收模型 `S` 的缓存格式 `Ĉ_S(d)`；学生从 `Ĉ_S(d)` 出发接收同一查询 `q` 并解码，**不再重新处理 `d`**。学生自己的 `C_S(d)` 仅用作离线训练参考、评测基线与机理干预的 Oracle，**绝不允许在所宣称的严格零重 Prefill 推理路径中使用**。

对照必须使用统一的文档切分、Query 拼接、位置偏置、RoPE 和 GQA 处理。Qwen3 的 QK-Norm 与模型专用聊天模板按真实结构实现；`/no_think` 或等价的确定性答题模式固定为同一协议，避免思考模式导致任务口径漂移。

明确不研究：

- 不把同一模型中对“旧缓存”的文档增量编辑修复作为核心目标；反事实条件的两份缓存必须**各自独立生成**。
- 不主张仅凭错误缓存下性能下降就证明信息充分传输；还须证实相对于原生接收模型的方向与幅度保真。
- 主方法不修改学生主干权重；若比较 adapter，明确它属于改变接收端的对照，不与纯 Mapper 同口径比较参数开销。
- 不把 K-only / V-only 这样的 Oracle 实验臂宣传为零重 Prefill 可部署方法，因为其另一半缓存来自学生自身 Prefill。
- 不把单卡短上下文性能直接推断为 32K 长上下文系统加速，长期系统收益必须单独测量。

## 3. 反事实基准：数据与任务的可执行设计

### 3.1 最小单元

每个评测单元 `u=(q, d_A, d_B, a, b, m)`：同一问题 `q`，两个在关键事实位点上不同的文档 `d_A`、`d_B`，互斥的可验证答案 `a/b`，元数据 `m`（模板族、实体集、替换位置、tokenization、长度、事实类型、干扰项、来源 / 许可、split）。

教师分别对 `d_A`、`d_B` **独立 Prefill**，绝不能通过篡改缓存字节“伪造另一文档”。

示例：`q=“项目A 负责人是谁？”`；`d_A` 写明“项目A 负责人张三”，`d_B` 写明“项目A 负责人李四”。为降低生成格式和名字 token 长度的干扰，主指标采用同一个两选一结构（候选 A/B 在每对文档内一致），要求 `d_A` 选 A、`d_B` 选 B；在数据集中**随机交换候选顺序**以控制答案位置偏差。

### 3.2 六类任务切片

| 切片 | 构造方式 | 主要排除的混淆 |
|---|---|---|
| F1 直接事实替换 | 只改变负责人 / 日期 / 数值 / 城市等目标事实，其余上下文恒定 | 文本位置与总体语境基本相同 |
| F2 推理链变化 | 改变中间别名、隶属或比较关系，正确答案位于另一个句段 | 只盯局部答案字符串的捷径 |
| F3 关系方向 / 否定 | A 属于 B 改为 B 属于 A；允许 / 禁止反转 | 词重叠但逻辑关系不同 |
| F4 干扰与指向 | 加入多个相似实体、同类信息及干扰段落 | 仅靠实体出现频率或位置选答案 |
| F5 表层等价 | 同一事实的同义改写、语序变化、无关格式变更 | 模型对表面扰动敏感但内容并未变 |
| F6 长度 / 位置控制 | 编辑 token 长度匹配；另建不匹配和位置移动子集 | 把 RoPE / 位置变化错误归因为事实不保真 |

F1—F4 采用语义变化成对样本；F5 是**不应产生答案翻转的负控制**；F6 是条件扰动。**不要把 F5 计入“必须翻转”的成功率分母**。需要包括同一语义的多个改写，以区分内容稳定性与训练模板适应。

### 3.3 规模与拆分（建议而非功效保证）

| 阶段 | 建议规模 | 拆分要求 | 目的 |
|---|---|---|---|
| 基础探针 | 32—48 对文档 | 至少 6 个模板族，不用于定稿统计 | 验证注入协议、任务可回答性和模式漂移 |
| 训练 / 验证 | 训练 120 对、验证 60 对 | 实体 / 文档无交叉；验证包含未见实体与同类模板改写 | 拟合 Mapper、选择超参与统计功效预估 |
| 封存测试 | 建议 240—360 对 | 至少 24 个独立模板 / 主题簇；另设未见模板子集 | 终稿主结果，禁止反复根据结果调超参 |
| 真实文档扩展 | 预算允许增设 80—150 对 | 人工核验出处与事实扰动；避免文档实体泄漏 | 验证是否仅对模板合成域有效 |

这些数字是首轮资源规划，**不是统计功效结论**。先用基础探针估算效应与簇内相关，再决定封存测试样本量。推断单位为“反事实文档对”，相关模板族 / 来源文档采用簇级重采样；对多模型、多任务显著性要控制多重比较。

### 3.4 数据质量门禁

- 两个文档应仅在预先标注的事实因子上发生语义变化；不可无意改变答案的可推理性。
- 候选答案标签与内容随机交换，保持相同问题、文档包装、提示模板。优先使用单 Token 的 A/B 标记；保留 tokenization 检查记录。
- 先计算学生 Self 的双文档回答；原生学生不能双向区分的样本仍保留在“全量任务”指标中，但预先定义的可评价子集用于迁移相对保真分析，并**报告覆盖率**，避免后验挑样本。
- 严格按实体、原始来源与任务模板做训练 / 评估隔离。若使用真实文档改写，记录编辑类型、人工抽检结论和授权来源。
- 同一个评测对的两个缓存应尽可能具有相同 token 长度；无法完全匹配时，单独分层报告 token 数差异和编辑位置，防止位置编码效应。

## 4. 指标与审计协议

### 4.1 统一输出口径

学生只比较固定候选 A/B 的条件分数，定义

```
g(C,q) = log P(A|C,q) − log P(B|C,q)
```

单 token 候选统一在同一生成位置提取 logits；若使用多 token 自由回答，需单独报告 corrected EM 和预定义的序列概率评分，**不能混合**。

```
D_self  = g(C_S(d_A),q) − g(C_S(d_B),q)
D_trans = g(Ĉ_S(d_A),q) − g(Ĉ_S(d_B),q)
E_CF    = |D_trans − D_self|
归一化误差 = |D_trans − D_self| / (|D_self| + τ)
```

`τ` 只从验证集固定，不可按测试结果调整。

**注意**：仅降低 `E_CF` 不保证信息正确利用。若 `D_self` 近零，始终输出相同分布也可能具有低 `E_CF`。因此必须共同报告：每个文档分别答对的双向成功率、响应方向保持率、原生 Self 可评价子集覆盖率、与无信息控制组的差距。

### 4.2 五类最小指标

| 层次 | 主报告指标 | 解释与局限 |
|---|---|---|
| 实现正确性 | Identity logit cosine、first-token KL、Self—Identity 差异、cache round-trip | 先确证位置、RoPE、评测器与保存 / 加载正确 |
| 替代能力 | 相对于 Self 的答案准确率 / Gold probability / EM、95% 簇级 CI | 不要求超越原生 Self；近原生替代与额外能力增益分开报告 |
| 反事实保真 | `E_CF`、`D_trans/D_self` 方向一致率、双文档同时答对率 | 主研究对象；同时报告全体和预注册 Self 有效子集 |
| 信息归因 | 正确缓存相对于错配、零、随机、无信息训练的净差 | 沿用公开因果审计原则；不是新增指标原创主张 |
| 系统成本 | Mapper 训练开销、教师预填成本、映射延迟、学生 TTFT、GPU 内存和磁盘存储 | 仅对真实可部署 Joint 臂计端到端推理收益 |

### 4.3 反事实指标族（主研究对象）

- `E_CF`：主终点，见 §4.1；在封存测试上比较新方法与最强行为基线的**成对 `E_CF` 差异**。
- `flip_consistency`：方向一致率 = `sign(D_trans) == sign(D_self)` 的比例（在 Self 有效子集上）。
- `dual_correct`：两个文档分别答对的比例（不是“必须翻转”成功率）。
- `coverage`：原生 Self 可评价子集占全量任务的比例，必须随同报告。
- `normalized_E_CF`：用验证集固定的 `τ` 做归一化，便于跨模型对比较。
- `info_gap`：正确缓存与错配 / 零 / 随机 / shuffled-target 控制在 `g` 或 `E_CF` 上的净差（沿用公开审计原则，不主张原创）。

### 4.4 错配 / 无信息审计组

- **Correct**：正确文档对应的教师 KV，经同一个最终 Mapper 注入。
- **Mismatch**：将其他成对任务中的教师缓存做形状与长度匹配的 derangement，不允许混入正确文档。
- **Random / Zero**：匹配统计量随机缓存、零缓存；若数值不稳定，报告无效样本与损坏方式。
- **Shuffled-target training**：训练数据真实标签与缓存内容解耦，固定训练预算并重新拟合。
- **Self / Identity**：学生原生 Prefill 与同路径注入的自身缓存；固定作为测量锚点。
- **Receiver-only adapted baseline**：若允许 adapter，必须用相同训练样本和预算训练无教师信号的参数高效模型。

### 4.5 统计设计

- **主要假设检验**：封存测试集上新方法与最强可复现行为基线之间的**成对 `E_CF` 差异**。
- 在验证阶段确定最小有意义差异（例如按原生响应尺度校准），并用试验数据估计所需样本。
- 置信区间采用**模板 / 来源簇级 paired bootstrap**；以至少 **3 个训练种子**报告方法方差。
- 若进行多项主检验，预先确定优先级或采用 **Holm 调整**。
- 不将 `P>0.05` 当作两方法等效的证明。不满足非劣效判据时应报告证据不足；如果要证明与 Self 等效，需要依据预先设定的容差开展真正的非劣效设计与功效计算。

## 5. 机制诊断判据

### 5.1 局部注意力扰动分解

给定同一个接收端 Query `Q_S` 与同一层输入，在该局部条件下记 `A_S = softmax(Q_S K_Sᵀ/√d)`、`Â = softmax(Q_S K̂_Sᵀ/√d)`，其输出差满足：

```
Ô − O_S = (Â − A_S) V_S W_O^S  +  Â (V̂ − V_S) W_O^S
          └──── Routing ────┘     └──── Consumption ────┘
```

第一项是 Routing 差异，第二项是 Consumption 差异。这是**固定 Q、固定位置与当前层**下的代数恒等式，**不能直接解释为全模型任务损失的加性因果分解**，因为前层注入还会改变后层 Q 与非线性状态。

### 5.2 四臂注入与局部 Oracle

| 实验臂 | Key | Value | 用途 |
|---|---|---|---|
| Self | 学生自身 | 学生自身 | 原生锚点；用于训练 / 诊断，非迁移成本 |
| K-only | 映射教师 | 学生自身 | 分离寻址扰动；非可部署严格零 Prefill |
| V-only | 学生自身 | 映射教师 | 分离读取扰动；非可部署严格零 Prefill |
| Joint | 映射教师 | 映射教师 | 唯一主方法的严格零重 Prefill 迁移路径 |

机制分析从三层推进：

- **A. 缓存层**：K/V `R²`、score 差、attention top-k / TV、`W_O` 输出误差。
- **B. 模型层**：候选答案响应差和 token-level KL。
- **C. 因果层**：在选定层 / Head / Token 用学生 Oracle 状态移植，观察 `E_CF` 改变。

A/B 只是关联，**C 才能帮助识别必要 / 充分的局部影响**。

### 5.3 两类效应必须分开

在 `d_A` 与 `d_B` 上分别诊断映射误差，然后比较它们的差值；**不能把普通单文档注意力差错直接当成反事实错误原因**。对每个层头记录“修复该单元后 `E_CF` 改善多少”，再用独立文档验证同类单元是否稳定重要。

部署限制：Oracle 移植依赖学生原生 Prefill，只能发生在**离线诊断阶段**。后续若要实现推理期的预算分配，必须训练只依赖教师缓存、映射状态、学生当前 Query 等**可观测量**的预测器，而不能在线读取 `C_S(d)`。

### 5.4 对称 Key 目标作为前置机制实验

比较：(i) per-head ridge；(ii) student attention-mass 加权回归；(iii) 对学生 pre-softmax score 的回归；(iv) attention KL / ranking 目标；V 侧暂固定 consumer-space Mapper。GQA 下按多个 Query Head 对应同一个 KV Head 聚合；对 RoPE 前 / 后回归分别测试，并报告位置扰动。

无论 Key 侧结果阳性与否，其定位仍是第二篇的对称性补全与第三篇的**机制基线**；仅当由此发现新型可迁移规律时，才可提升为方法主贡献。

判据（跑前冻结）：C（score 回归）显著优于 A/B 且 D（另一文档 target）不优于 C 为阳性；routing 改善而 `E_CF` / EM 不动为阴性，指向 query–key 交互或需重算。两种结果都写入论文。

## 6. 主方法与公平比较

### 6.1 候选架构 CF-RCT（工作名）

`CF-RCT`（Counterfactual Response-Constrained Translation）仅作为候选算法名，避免抢先声明发明。以一个可学习的 K/V Mapper `gθ` 为主体；**学生模型所有主权重冻结**。教师先离线生成 K/V，训练时由固定学生从映射缓存读取答案 logits 与选定层注意力统计。

Mapper 参数化从低风险起步：① per-(layer,head) affine + 层映射；② 加低秩残差修正；③ 仅当显著必要时加入小型跨层 Mixer。模型容量逐级控制，以防仅靠更多参数解释全部增益。

### 6.2 训练信号

```
L_KD    : 对 d_A、d_B 分别计算学生原生缓存预测分布与迁移缓存预测分布的 KL（与 KV-Lingo 构成直接强基线）
L_CF    : 对每个成对文档，取 D_trans 与 D_self，使用 Huber(D_trans−D_self) 或固定尺度的平方损失；两份文档须共享 Mapper 参数并成对更新
L_local : 可选机制约束，包括 attention score / routing 分布一致和经 W_O 投影后的 Value 消费输出一致
L_reg   : 对映射参数或残差做适当正则，避免在小型合成域上过拟合

L_total = λ_KD·L_KD + λ_CF·L_CF + λ_local·L_local + λ_reg·L_reg
```

需在验证集固定 `τ`、Huber 阈值和标签平衡策略。`L_local` 计算时固定接收端局部 Query，并注意其作为 **Oracle 训练信号只允许在训练期使用**。

总损失并非理论新颖性的充分证据。必须在同一成对数据、相同接收端 Forward 次数、相同可训练参数数目和超参搜索预算下，与 KD-only、答案 CE-only、简单错文档对比、Consumer-space 回归、强行为 Mapper 对照。**若新增 `λ_CF` 不增加效果，不能将其作为主要方法贡献。**

### 6.3 避免目标退化的保护机制

- 同时保留单文档的原生预测一致性和答案正确率，不能允许模型以降低负样本概率来虚增真—假差值。
- 所有反事实改写必须是逻辑一致的：`d_A` 下答案 `a`、`d_B` 下答案 `b`；引入同义改写“非翻转”样本作反控制。
- 在 Self 原生不具可辨识信息的样本中，不能强行要求 Mapper 比 Self 更敏感；另行报告监督下的任务正确率，不与 fidelity 概念混用。
- 报告是否仅拟合模板 / 实体字面特征，增加未见模板、同义实体与位置偏移测试。

### 6.4 机制感知版本与单纯成对 KD 的区分

建议设计 `CF-RCT-lite`（仅 `L_KD + L_CF`）和 `CF-RCT-mech`（加入由局部干预选出的层 / Head 机制约束）。机制选择规则**仅从训练 / 验证集学习**，不使用封存测试标签。只有 `CF-RCT-mech` 对 `CF-RCT-lite` 和最强公共基线均有额外增益，才可以将“机制引导”写成核心方法创新。

### 6.5 Hidden State 路线作为候补分支

若纯 KV 映射停滞，可验证 `Ĥ_S = f(H_T)`，再由学生原生 `W_K/W_V` 投影得到缓存。这一方向**并非首创范式**，且学生本身的 Q、层间状态与位置结构仍会不兼容；先限定于一对模型、相同预算的诊断实验。若不能在 `E_CF` 与 Joint 任务结果上稳定超过直接 KV 映射，应停止扩展。

## 7. 完整实验矩阵

| 编号 | 对比 / 干预 | 主指标 | 必须回答的问题 |
|---|---|---|---|
| E0 | Full Prefill vs Identity vs cache round-trip；不同 kernel 一致性 | top1、KL、logit cosine | 测量误差上限是否显著低于待研究效应？ |
| E1 | Ridge / Affine / consumer-space / KD baseline / Joint | `E_CF`、双向成功率、Self Gap | 已知强方法是否存在可重复的反事实失真？ |
| E2 | K-only / V-only / Joint；Key score / KL；层 / 头局部移植 | 局部误差、`E_CF` 变化 | 路由和消费哪一个更关键、是否相互作用？ |
| E3 | KD-only vs KD+CF vs KD+CF+Local vs CE/contrastive | `E_CF`、任务分数、无信息控制 | 反事实损失与机制约束是否带来独立增益？ |
| E4 | 同域未见实体、未见模板、真实文档扩展 | 分组 `E_CF` 与置信区间 | 是否仅记住合成模板？ |
| E5 | 等深 1.7B→0.6B、非等深 4B→1.7B | `E_CF` 与标准 QA | 是否跨结构 / 尺度保持？ |
| E6 | 映射延迟、TTFT、成本、存储 | 端到端时间 / 峰值显存 | 是否真正值得替代学生重 Prefill？ |
| E7（可选） | Hidden-state / 选择性重算 | 质量—预算曲线 | 何时应从零重 Prefill 切换到混合方案？ |

公平比较最低要求：

- 优先复现 KV-Lingo 的同模型对、同协议行为蒸馏；CacheLink 若缺少可运行官方实现，应按公开文档实现并明确报告偏差，不假定其原作者结果可在当前任务直接复现。
- 只用与新方法相同校准文档和反事实对，不允许新方法额外看到测试领域样本。
- 对齐可训练参数、Transformer Forward 预算、训练步数、学习率调参次数，并单独报告超参搜索成本。
- Full-Prefill、Self 和 Identity 为评测锚点，**不计作可部署跨模型性能**；只对 Joint 映射进行严格零 Prefill 主报告。
- 普通 QA 与反事实 QA 均应报告，防止“新指标改善但常规任务退化”。

## 8. 决策树：避免无论结果如何都声称创新

| 关键发现 | 后续主线 | 不应做的事 |
|---|---|---|
| 强基线在反事实任务上已接近 Self | 转向泛化边界 / 失败条件研究，优先真实任务或非等深场景 | 坚持“所有方法反事实失真”这一前提 |
| 强基线有失真，但机制诊断无跨样本预测 | 可报告现象，继续改进可检验诊断 | 把局部热图直接解释为因果理论 |
| 机制诊断有效，CF 方法不优于 KD | 把机制 / 评测证据独立整理，方法贡献降级 | 用挑选种子或任务掩盖无效 |
| CF 方法改善 `E_CF` 但降低真实任务质量 | 重新调整多目标约束；如不能兼顾，则如实报告权衡 | 只报告新指标并省略常规任务退化 |
| 效果仅在合成域成立 | 明确适用域并检查模板泄漏、容量与语义变化构造 | 宣称通用跨家族 / 真实世界迁移 |
| 机制与方法均稳定优于强基线 | 补齐跨模型、成本、统计、公开代码与论文叙事 | 在尚未核算推理成本时宣称高倍率加速 |

## 9. 预注册与可复现性

封存测试运行前固定：主要指标 `E_CF` 的定义、Self 有效样本阈值与全量报告方式、任务切片、模型配置、最强基线清单、主要统计检验与多重比较处理。

- 训练校准集与封存测试集按文档来源、实体和模板簇隔离；记录训练样本去重摘要、模型版本、代码 commit、驱动 / CUDA 版本、dtype 和 Attention backend。
- 记录每对文档的 teacher cache、student Self、mapped cache 的 shape、层映射、RoPE 元数据与问答日志；保留错配缓存的具体配对索引以供审计。
- 实施分布外对照：同义改写、答案位置变化、模板未见、同 / 不同实体结构；公开有条件复现的最小数据与指标脚本。
- 引用 2026 年同期工作时，核查正式版本、日期与实验口径；尤其要分清**跨模型传输、同模型增量编辑缓存修复、无信息消息适应和内容依赖审计**四个研究范畴。
- 若主结果很小，使用至少 3 训练种子、合理簇数量和效应区间，不用“若干 seed 均值略高”作强结论。

## 10. 贡献表述门槛（条件性）

只能在实验通过后使用的贡献模板：

1. We identify a reproducible gap between standard transfer utility and counterfactual response fidelity in cross-model KV handoff.
2. We localize the gap to receiver-side routing and consumption effects under controlled cache interventions.
3. We present a mechanism-constrained mapper that reduces this gap against matched behavioral baselines without target-side re-prefill at inference.

如果仅第 (1) 项成立，应改写为边界 / 实证研究论文，**不能保留第 (2)(3) 条未被证实的措辞**。
