## 1. 新实验的独立复核

B0 `35e78e0` 之后，数据、模型评分代码、实验入口、统计脚本和判据在 Git 中没有变更。验证了 6 个正式格的 **12 个输入哈希、24 个归档文件哈希和 720 条分数行**。核对了 **2,880 条分支记录和 5,340 次 forward**，包括每个候选前缀指纹与实际输入、每次位置与缓存长度、同样本在不同臂上的查询指纹，以及分支 ID。420 个单 token 分支的整串与首 token 分数精确相同。六格可纳入研究证据。GPU 结果核对基于档案。 [运行示例](../runs/audit_seq_A11_s0_b0/manifest.json) · [实现](../../src/readkv/models/gpu_backend.py)

### 1.1 整串评分保留方向，效应幅度有变化

在 F1–F4 且候选相异、金标签互换的主分析中，A11 每 seed 46 对，A00 为 42/42/41 对，每格 6 个模板族。以下是独立从分数与金标签复算的百分点结果。L 为 Self 的双侧正确率减 Joint 的双侧正确率。

| 统计量（百分点） | seed 0 | seed 1 | seed 2 |
| --- | ---: | ---: | ---: |
| A11 L，首 token | 43.48 | 65.22 | 43.48 |
| A11 L，完整候选 logprob | 47.83 | 43.48 | 52.17 |
| A11 L，长度归一 | 50.00 | 50.00 | 63.04 |
| A11−A00，首 token | 43.48 | 74.74 | 38.60 |
| A11−A00，完整候选 logprob | 47.83 | 50.62 | 47.30 |
| A11−A00，长度归一 | 50.00 | 57.14 | 58.17 |
| 整串相对首 token 对 A11−A00 的变化 | +4.35 | −24.12 | +8.70 |

样本加权的模板族重采样复现了归档的主要区间。例如 seed 1 的整串相对首 token 让 A11 的 L 减少 **21.7 [−34.0, −13.0]** 点，同时让 A11−A00 减少 **24.1 [−39.8, −10.5]** 点。A11 seed 1 的 Self 从 **87.0% 降到 73.9%**，Joint 从 **21.7% 升到 30.4%**，两个水平变化均对 L 的收窄有贡献。这是本轮读者应看到的主要结果之一。建议将 Self/Joint/L 同列，并让摘要正文各用一句概括「三组方向一致、幅度因评分方式而变化」，将 6 簇探索性说明保留。A01/A10 未采用整串评分，证据仅覆盖 A00/A11，2×2 的交互稳健性没有测量。 [序列评分统计](../../docs/audit_seq_statistical_interpretation.md) · [匿名稿序列评分节](../../papers/readkv_v2_tmlr_anonymous/main.tex)

候选边界也可复核。360 个验证对中，没有观察到查询与候选的分段拼接差异。主分析内候选没有共享首 token，也没有候选互为真前缀。三个 A11 seed 各有 7 对候选长度不等，A00 主分析均等长。保留 A11 等长的 39 对作附加描述性核验，三组整串 L 仍为 **48.7、43.6、56.4** 点，说明方向在等长子集也保留。该子集属于本轮审查的附加核验。论文可以把整串评分解释为两条固定候选 token 序列的条件对数概率和，明确未追加 EOS，并把「会共享首 token」作为一般动机，避免读者误解为主分析集有该冲突。

### 1.2 规则问题：首 token margin 对上，分类标签并未完全回放

六格全部 720 对臂级首 token D 与旧 2×2 的最大绝对差为 **1.43×10⁻⁶**，在 0.02 容差内。逐对 **dual 有 90/720 条差异**。旧评分器用 `np.argmax`，同分取 A。新入口的 `g > 0` 同分取 B。84 条差异来自 F5 的 `A/B` 标签：识别函数要求字符串同时以 A 和 B 开头，条件永远无法满足，而旧 scorer 恰好因同分取 A 得到 1，新 scorer 得到 0。其余 6 条来自 F2/F3 的确切同分。

我用现存 `g` 在 CPU 上重算，同分取 A，并显式接受 `A/B` 的两个答案，**720/720 个首 token dual 与旧记录一致**。这会改变 A11 seed 0 和 A00 seed 1 的首 token L 等数值，整串主分析的 L 和方向保持。统一后的整串结果仍支持科学主张。建议保留 B0 原文件，把修正写入新统计层并回归测试，更新稿件的表和历史回放声明。 [旧评分器](../../src/readkv/evaluate/counterfactual.py) · [v2.8 评分函数](../../experiments/sequence_scoring_gpu.py) · [冻结同分规则](../../configs/prereg/full_candidate_scoring_v2.8.yaml)

另一个复算风险是 `postprocess()` 把 Joint 对 Self 的同一 E_CF 同时写进 Self、Joint 行。Self 行用于去取配对信息时可以明确命名，通用 `bootstrap_ci_report` 现在会把它聚合为 Self 自己的误差。例如 A11 seed 0 的 Self 和 Joint 都被报告为首 token E_CF **6.900**，而按「当前臂相对于 Self」定义 Self 应为零。这未改变本轮主指标 L 或 Joint 的误差。建议在统计出口归零 Self 的同名指标，或将配对差放在单独字段，只对 Joint 臂生成转移误差。 [序列评估后处理](../../experiments/sequence_scoring_gpu.py) · [通用统计入口](../../scripts/bootstrap_ci_report.py)

### 1.3 预先约定与判读的表述

v2.8 的第一分支条件可以逐条核实。第二分支是析取条件，单独包含「A11 下降明显缩小」，文件未定义“明显”的阈值和分支冲突的优先级。seed 1 降了 21.7 点，区间也排除零，不能用“仍为正”证明缩小这一条没有触发。保留原规则，公开说明「方向保留、幅度敏感」，省去“第二分支无条件未触发”。此外，Git 仅能独立证明 **B0 正式重跑前已提交 v2.8**。可见的首个 v2.8 提交也是收录早期产物的 B0（北京时间 08:16），旧 A11 seed 0 归档早于它（07:50）。若另有早于首次试跑的带时戳冻结记录，可以附上。当前可直接写「方案在可复现 B0 重跑前已版本化」。这个限制约束预注册强度，核心结果仍可作为探索性复验呈现。 [v2.8 分支定义](../../configs/prereg/full_candidate_scoring_v2.8.yaml) · [早期运行配置](../runs/audit_seq_A11_s0/config.json) · [B0 配置](../runs/audit_seq_A11_s0_b0/config.json)

## 4. 复审决定

**有条件认可研究证据，建议修订后提交。** 最优先是以归档首 token 同分规则重算分类，纠正 Self 泛用统计及两个版本的区间表，主文显示 Self 和 Joint 并报告 seed 1 的幅度敏感性。然后用官方模板生成一份可阅读的匿名 PDF 和匿名复算附件。上述事项现有证据足够，暂时无需追加 GPU；只有论文扩大到「整个 2×2 交互在整串评分下也稳健」时，才有理由补 A01/A10。原稿、代码及运行归档保留，此次新增本文，其他验证在临时目录或内存完成。
