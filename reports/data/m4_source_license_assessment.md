## 0. 红线（不可逾越）

> **五项登记齐全 + PI 合规签off 之前，不得入库任何真实文档，不得进入主实验，不得启动任何 real/锚点 GPU run。**

"五项登记"指每份来源必须归档：
1. **来源 URL/标识**（含永久链接/修订号/存档快照）；
2. **版本 / 日期**（数据版本、页面修订日期、抓取日期）；
3. **许可证原文**（完整文本或明确链接 + 快照，含署名与相同方式共享条款）；
4. **原始文件 sha256**（下载原文件字节哈希）；
5. **处理脚本 commit**（抓取、清洗、反事实编辑脚本的 git 哈希）。

补充硬约束：许可不明 → 该来源整批剔除，不勉强凑数；禁止再分发、仅限研究且不允许发布衍生、需签未获协议、含未脱敏个人数据的文本 → 一律不纳入；真实文档只入独立 `real` split，**绝不并入合成 test**、不参与任何已冻结主终点。

## 2. 候选来源具体渠道与示例（均待核验，本轮未抓取）

### 2.1 优先级①：公共领域 / 政府公开文本（首选）

| 具体渠道/示例 | 事实类型适配 | 许可类型（预评估，须核验） | 义务 | 允许改写/发布衍生？ | 风险 |
|---|---|---|---|---|---|
| 中国中央政府门户 / 国务院公报（gov.cn 系列） | 政策公告、机构职责、时间/数字事实 → F1/F3/F6 | 政府信息公开；常见为"注明出处可转载"，但部分页面保留权利声明 | 多要求注明来源；部分禁止商业用途 | 多数允许注明出处后使用；**须逐页核验** | 低—中 |
| 国家统计局公开统计公报 / 年鉴摘要（stats.gov.cn） | 数值、比例、时间事实 → F1/F6 | 官方发布；版权与再使用条款须逐份核验 | 注明出处；核查是否含个体数据 | 通常允许引用与摘录，改写发布须核验 | 低—中 |
| 美国联邦政府公开文本（如 census.gov、usa.gov、NIH/PubMed 摘要） | 人口/科学事实 → F1/F2/F6 | 美国联邦政府作品通常属公共领域（第三方内容例外） | 无强制署名，但建议记录来源 | 通常可自由改写与再分发；**须核验具体页面是否含第三方材料** | 低 |
| 欧盟 / 国际组织开放数据门户（如 data.europa.eu、联合国/世卫公开报告） | 统计、政策事实 → F1/F6 | 多为 CC BY 4.0 或组织自有开放条款 | 署名；可能禁止商业用途或要求保留声明 | 多允许，须核验具体数据集条款 | 低—中 |

**为何首选**：版权状态相对清晰、事实可核验、易做实体替换；适合构造 F1（直接事实替换）、F3（关系/方向）、F6（长度/位置）的真实对应。
**主要风险**：(a) 部分政府页面版权声明不统一，须逐页归档；(b) 统计/公告可能含个人数据，须剔除或脱敏；(c) "允许引用"不等于"允许改写并作为数据集发布"，须确认再分发权。

### 2.2 优先级②：Wikipedia / Wikidata（条件接受）

| 具体渠道 | 许可类型（预评估，须核验） | 义务 | 允许改写/发布衍生？ | 风险 |
|---|---|---|---|---|
| Wikipedia 条目正文（en/zh） | 通常 **CC BY-SA 4.0**（历史材料可能 CC BY-SA 3.0 / GFDL 双重许可） | **署名**（作者/标题/来源/许可/注明修改）+ **相同方式共享（SA）**：衍生数据集须以 CC BY-SA（或兼容）发布 | 允许改写与再分发，**但衍生集必须同许可发布** | 中 |
| Wikidata 结构化数据（实体/别名/陈述） | 数据通常以 **CC0 1.0** 发布（不含 Wikipedia 正文） | 无强制署名（CC0 弃权），建议记录来源 | 通常可自由改写与再分发 | 低—中 |

**关键区分**：Wikidata 的**结构化数据**（CC0）与 Wikipedia 的**正文文本**（CC BY-SA）许可不同。若用正文句子做反事实编辑，real split 衍生数据集可能被 SA 义务约束为 CC BY-SA 发布——**这是需 PI 明确签off的核心待决项**（见 §5）。
**主要风险**：(a) SA 义务影响本项目数据集的发布许可（当前合成数据为 CC0）；(b) 署名须记录逐条修订版本与作者列表，登记负担重；(c) 不同语种/镜像许可声明可能不同，须逐页快照；(d) 页面版本变动 → 须用永久链接/修订号固定版本。

### 2.3 优先级③：学术基准（仅锚点，不改写成 real）

| 基准 | 用途 | 许可（预评估，须核验发布页当前条款） | 义务 | 是否改写/发布衍生 | 风险 |
|---|---|---|---|---|---|
| SQuAD（抽取式 QA） | PI 指定**首选锚点**；事实定位语义最接近 | 常见标注 CC BY-SA（版本间不同，须核验当前发布页） | 署名 + 可能的 SA | **否**：仅按自身 license 用于评测，不改写/不发布衍生语料 | 中 |
| ARC（选择题科学 QA） | **次选锚点**；A/B 候选结构相近 | 多为研究用途/开放许可（须核验） | 依条款署名/研究用途限制 | **否**：仅评测 | 中—高 |
| HellaSwag（常识补全） | 可选补充旁证，可比性较低 | 多为研究用途许可（须核验） | 依条款 | **否**：仅评测 | 中—高 |

**纪律**：锚点数据**不得**进入 real split 做反事实改写，不得再发布其语料；仅按各基准自身 license 合规用于评测（呼应 PI 执行计划 §1.1 / §2.1）。若某基准当前许可不允许本项目用途 → 换用次选，不强用。

### 2.4 优先级④：内部语料（本轮不采用）

无明确授权文件路径，合规范围不透明 → 本轮排除，不列入候选。

| 许可 | 署名 | 相同方式共享 SA | 再分发 | 改写/衍生 | 对本项目数据集许可的影响 |

## 4. 版本 / 日期 / 哈希登记方式（五项登记的落地细节）

建议在 `data/tasks/` 下为每份来源建立登记条目（**本轮只定格式，不创建实际来源记录、不抓取**），供后续入库脚本与 manifest/数据卡引用：

```
source_id              : 稳定标识，如 src-gov-cn-0001 / src-wiki-0001
source_url             : 永久链接 / 修订永久链接（Wikipedia 用 oldid）
source_title           : 标题
publisher              : 发布机构
version                : 数据/页面版本号（如 Wikipedia revision id）
source_date            : 页面修订日期 / 发布日期
retrieval_date         : 抓取日期（UTC）
license_id             : 许可标识（public-domain / CC0-1.0 / CC BY 4.0 / CC BY-SA 4.0 / gov-open-...）
license_url            : 许可证官方链接
license_text_sha256    : 许可原文快照文件的 sha256
raw_file_sha256        : 下载原始文件字节 sha256
attribution_record     : 署名文本（作者/标题/来源/许可/修改说明）
processing_commit      : 抓取+清洗+编辑脚本 git hash
pi_signoff_ref         : PI 合规签off 的记录引用（无签off 则留空 → 禁止入库）
```

登记纪律：原始文件与许可快照落盘后再计算 sha256；Wikipedia 必须用 `oldid` 固定版本；所有日期用 UTC；`pi_signoff_ref` 为空的条目一律不得进入任何主实验数据文件。

## 6. 需 PI 合规签off的具体来源清单与待决项

### 6.1 待签off来源清单（本轮只申请"允许进入抓取与许可核验阶段"，非允许入库）

| # | 来源渠道 | 拟用许可类型 | 用途 | 签off请求 |
|---|---|---|---|---|
| A | 美国联邦政府公开文本（census.gov 等） | 公共领域（逐页核验） | real 文档源（F1/F3/F6） | 是否授权抓取并做五项登记 |
| B | 中国中央/统计公开公报（gov.cn / stats.gov.cn） | 政府开放条款（逐页核验） | real 文档源（F1/F6） | 是否授权抓取；含个人数据者是否剔除/脱敏 |
| C | Wikidata 结构化数据 | CC0 | real 文档源（视语义适配） | 是否授权抓取与改写发布 |
| D | Wikipedia 正文（en/zh） | CC BY-SA | real 文档源 | **是否接受 SA 义务（见 6.2 待决项 1）** |
| E | SQuAD | 按发布页当前许可 | 外部锚点（仅评测） | 是否授权评测使用、是否需署名披露 |
| F | ARC | 按发布页当前许可 | 外部锚点（仅评测） | 同上 |
| G | HellaSwag | 按发布页当前许可 | 可选锚点（仅评测） | 是否启用 |

### 6.2 待决项（需 PI 明确裁定）

1. **是否接受 CC BY-SA 的相同方式共享义务**（最关键）：若接受，real split 衍生数据集须以 CC BY-SA 发布（与当前合成数据 CC0 不同），需在数据卡/论文数据可得性声明中区分两套许可；若不接受，则 Wikipedia 正文整批剔除，仅用 CC0/公共领域源。
2. **政府文本"允许引用"是否视为"允许改写并作为数据集发布"**：若某页条款只授权引用、未明示再分发，是否剔除。
3. **署名记录的细粒度**：Wikipedia 是否要求逐条记录作者列表与修订号（登记负担 vs 合规充分性）。
4. **锚点基准的使用边界确认**：确认 SQuAD/ARC/HellaSwag 仅评测、不改编、不再发布，且按各自 license 披露引用。
5. **个人数据处理**：公告/统计中含个人信息者，统一剔除还是脱敏后使用（建议剔除）。
6. **real split 数据集最终许可**：若混合公共领域与 CC BY 来源，是否统一按最严格义务（署名）披露。
